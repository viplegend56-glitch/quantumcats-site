# Quantum Cats — the website

One file: `index.html`. It talks to the brain on Railway (the `BRAIN_URL` in the CONFIG block near the top).

Hosted on GitHub Pages. To update the site: Add file → Upload files → drop the new `index.html` → Commit changes. Live within a minute or two.

`CNAME` holds the custom domain; leave it in place. `.nojekyll` tells GitHub to serve the files as they are.
